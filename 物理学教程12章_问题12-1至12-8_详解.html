M1 · 磁通量与楞次定律：判定感应电动势的方向

知识点

① 磁通量：按代数计算的磁感线条数，可正可负。

\[ \Phi=\int_S \mathbf{B}\cdot d\mathbf{S}, \qquad \Phi=BS\cos\theta\ (\text{匀强磁场、平面回路}) \tag{1-1} \]

θ 是 B 与回路正法线 e_n 的夹角。正法线一旦选定，Φ 的正负随之确定。改变 Φ 只有三种途径：B 变、S 变、θ 变。

② 长直电流的磁场：

\[ B=\frac{\mu_0 I}{2\pi r} \tag{1-2} \]

方向用右手螺旋定则：右手握住导线、拇指指向电流方向，四指弯曲的方向就是 B 的绕行方向。本题电流向上，线圈在导线右侧，该处 B 垂直纸面向里，且离导线越远越弱。

③ 楞次定律：感应电流的磁场总要阻碍原磁通量的变化。Φ 增加时感应磁场与原磁场反向（“增反”），Φ 减少时同向（“减同”）。得到感应磁场方向后，再用右手螺旋定则把“磁场方向”换成“电流绕行方向”。

④ 等效判据：感应电流的效果总要使回路与外界的相对运动受到阻碍（靠近相斥、远离相吸），用来快速核对方向。

解题方法
  1. 定正方向：选正法线 e_n，并写出与它配套的回路的正绕行方向（右手螺旋）。
  2. 判原磁场方向：长直导线用 (1-2) 的右手螺旋；条形磁铁用“外部磁感线从 N 极出发、回到 S 极”。
  3. 判磁通量增减：看 B、S、θ 三者中谁在变，写出 Φ 的增减。
  4. 定感应磁场：Φ 增则与原磁场反向，Φ 减则与原磁场同向。
  5. 定电流方向：右手拇指指向感应磁场，四指为电流方向；用字母序列（如 A→D→C→B→A）记录结论，避免“顺时针”在图上产生歧义。
适用条件：闭合回路；只求方向、不求大小。 本模块易错点：跳过“定正方向”直接判方向；把导线两侧的 B 方向当成相同。

题 12-1(1)　线圈在纸面内向右移动

题目重述

如图所示，在一长直导线 L 中通有电流 I，ABCD 为一矩形线圈。试确定在下列情况下，ABCD 上的感应电动势的方向：(1) 矩形线圈在纸面内向右移动。

L I A D B C
图 12-1 示意：电流 I 向上，线圈在导线右侧，A、D 为上边两端，B、C 为下边两端。
第0步 · 三类检查

(i) 存在性与模型前提：导线足够长，可用无限长直导线的磁场；线圈刚性、整体平动；回路始终闭合，面积不变。

(ii) 多值与分支：电流方向有顺、逆两种可能，必须先约定回路的正绕行方向。本文把正法线取为垂直纸面向里，与 B 同向。

(iii) 取值范围：线圈始终在导线右侧（r 大于 0），B 的方向不变（始终向里），只有 B 的大小随 r 变化。

思路

路线甲：磁通量法。判断 Φ 的增减，用楞次定律定感应磁场，再用右手螺旋定则换成电流方向。

路线乙：动生电动势法。用洛伦兹力 F=qv×B 分别算 AB、DC 两边的电动势，再比较。

选甲：一次判断即得方向；乙要比较两条边，正好留作验证。

分步推导
  1. 判 B 的方向：导线中电流向上，由右手螺旋定则，线圈所在的右侧空间磁场垂直纸面向里。（依据：(1-2)）
  2. 定正方向：取正法线 e_n 垂直纸面向里，与 B 同向，于是 Φ 大于 0。（依据：(1-1)）
  3. 判 Φ 的增减：线圈向右移动，各点到导线的距离 r 增大，B 按 (1-2) 减小；线圈面积 S 不变，所以 Φ 减小。（依据：(1-2)、(1-1)）
  4. 定感应磁场：Φ 减小，按“减同”，感应电流的磁场与原 B 同向，即垂直纸面向里。依据：楞次定律（增反减同）旁注 · 楞次定律的完整表述感应电流的磁场总要阻碍引起感应电流的磁通量的变化：Φ 增加时，感应磁场与原磁场反向；Φ 减少时，两者同向。它阻碍的是“变化”，不是“磁场本身”，所以原磁场很大但不变化时没有感应电流。本题用法：Φ 减小，所以取“同向”，感应磁场仍向里；下一步用右手螺旋把它换算成电流方向。。
  5. 定电流方向：右手拇指指向纸面内，四指绕行方向为顺时针，即 A→D→C→B→A。（依据：右手螺旋定则）
  6. 写成结论：感应电动势沿回路 A→D→C→B→A 方向（顺时针）。
答案\[ \boxed{\text{顺时针，即 } A\to D\to C\to B\to A} \]
验证

独立路径（洛伦兹力）：线圈速度 v 向右，B 向里，正电荷受力 F=qv×B 向上。AB 边（近导线）中电动势由 B 指向 A，DC 边（远导线）中由 C 指向 D，两边反向；AB 处 B 更大，故净电动势沿 B→A→D→C→B 的顺时针方向： \[ \varepsilon_{\text{净}}=vh\left[B(x_1)-B(x_2)\right] \gt 0 \] 其中 h 为线圈高度，x1、x2 为 AB、DC 两边到导线的距离。这与第 5 步的结论一致。

合理性检查：线圈向右是在“逃离”导线，感应电流使 AB 边受到指向导线的安培力（电流向上、B 向里，安培力向左），恰好阻碍这一运动，符合能量守恒。

常见坑
① 把导线右侧的 B 判成“垂直纸面向外”，全部方向反向。核对方法：右手握导线、拇指向上，右侧四指弯向纸内。
② 以为“只有靠近导线的 AB 边切割，DC 边没有电动势”。DC 边同样切割，两侧电动势方向相反，净电动势是两者之差。
③ 凭“向右移动离磁场更远，磁通应该更大”的直觉。长直导线的 B 随距离减小，磁通量是减小的。

题 12-1(2)　线圈绕 AD 轴旋转

题目重述

条件同 12-1：长直导线 L 中通有电流 I，ABCD 为导线右侧的矩形线圈（A、D 为上边两端）。试确定：(2) 矩形线圈绕 AD 轴旋转时，ABCD 上的感应电动势的方向。

第0步 · 三类检查

(i) 存在性与模型前提：线圈绕纸面内的 AD 边转动（AD 垂直于导线），角速度记为 ω；导线足够长。线圈有宽度，B 在宽度方向不完全均匀，推导中会写明所用的近似。

(ii) 多值与分支：θ 取线圈平面与纸面的夹角，θ=0 为初始位置。正法线必须随线圈连续转动，因为 θ 越过 90° 时磁通量变号，符号要连续跟踪，不能中途重新定义。

(iii) 取值范围：讨论 θ 从 0 到 π 的半圈。θ=0 时线圈在纸面内；θ=π/2 时线圈平面垂直于纸面；θ=π 时回到纸面内，但正反面互换。

思路

路线甲：磁通量法。写出 Φ(θ)，看 dΦ/dt 的符号，再定方向。

路线乙：动生电动势法。判断转动中哪条边在切割磁感线。

选甲：与 (1) 用同一判据，结论可以直接比较；乙放在验证里，用来核对“方向不反转”这一结论。

分步推导
  1. 定角：令 θ 为线圈平面与纸面的夹角，初始 θ=0。
  2. 写磁通量：把线圈范围内的 B 视为近似均匀（线圈尺寸远小于它到导线的距离时成立），穿过线圈的磁通量只由投影面积决定： \[ \Phi(\theta)=\Phi_0\cos\theta \] Φ0 为 θ=0 时的磁通量，取向里为正。（依据：(1-1)）
  3. 判第一段（θ 从 0 增到 π/2）：cosθ 减小，Φ 减小。（依据：cosθ 在 0 到 π/2 上单调减）
  4. 定方向：按“减同”，感应磁场向里，电流顺时针，与 (1) 相同。（依据：楞次定律，见 投影面积旁注 · 为什么用投影面积磁通量只认“穿过回路的场”，回路倾斜 θ 时，它在垂直于 B 的平面上的投影面积变为原来的 cosθ 倍，所以 Φ=Φ0cosθ。θ=90° 时投影面积为零，磁通量为零。本题用法：转动过程中 cosθ 单调减小，磁通量从最大值降到零；越过 90° 后取负值，表示磁通方向反过来，但代数值仍在减小。。
  5. 判第二段（θ 从 π/2 增到 π）：cosθ 为负，Φ 变成“指向纸外”，且代数值继续减小（更负），也就是向外的磁通在增大。按“增反”，感应磁场仍向里，电流方向不变。
  6. 写大小：在上述均匀近似下，ε=-dΦ/dt≈Φ0ωsinθ，在 θ=0 与 θ=π 处为零，在 θ=π/2 附近最大。（依据：(2-1)）
答案\[ \boxed{\text{方向与 (1) 相同，沿 } A\to D\to C\to B\to A;\quad \varepsilon\approx\Phi_0\omega\sin\theta\ \text{（均匀近似）}} \]
验证

独立路径（三维磁场下的严格磁通量，不依赖均匀近似）：倾斜后线圈上一点到导线的距离满足 r²=x²+d²sin²θ，其中 x 为该点到导线的距离，d 为该点到 AD 的距离。该点磁场 B=(μ0I/2π)(z,0,-x)/r²，其中 z=-dsinθ；面积元法线 dS=(0,sinθ,-cosθ)dx dd。点乘后只有 B 的 z 分量留下： \[ d\Phi=\frac{\mu_0 I}{2\pi}\cdot\frac{x\cos\theta}{x^2+d^2\sin^2\theta}\,dx\,dd \] 对 x、d 积分得 Φ(θ)=cosθ·J(θ)，其中 \[ J(\theta)=\frac{\mu_0 I}{2\pi}\iint\frac{x}{x^2+d^2\sin^2\theta}\,dx\,dd \gt 0 \] θ 从 0 到 π/2 时 cosθ 减小、sin²θ 增大使 J 减小；θ 从 π/2 到 π 时 cosθ 为负且绝对值增大、sin²θ 减小使 J 增大，两项都使 Φ 继续减小。所以 dΦ/dθ 在 (0,π) 内恒为负，ε=-dΦ/dt 的符号不变，方向与 (1) 相同。J 只依赖 sin²θ，在 θ=0 与 θ=π 处导数为零，所以这两点 dΦ/dθ=0、电动势为零。

合理性检查：半圈内 Φ 从 +Φ0 单调降到 -Φ0，中途没有“由减变增”的时刻，所以方向不会反转；θ=π/2 是 Φ 的零点，不是极值点，恰好也是电动势最大的位置，两者不矛盾。

常见坑
① 只判到 90° 就收笔，认定“转过垂直位置后方向反转”。越过 90° 后是“向外的磁通在增大”，按“增反”判，方向与前一阶段相同。
② 把 θ 定义成“B 与线圈平面的夹角”，于是写成 sinθ：cos 与 sin 互换，最大、零点全部错位。
③ 认为“刚一转就有最大电动势”。θ=0 时 dΦ/dθ=0，电动势为零，随后才增大。

题 12-1(3)　线圈以直导线为轴旋转

题目重述

条件同 12-1：长直导线 L 中通有电流 I，ABCD 为导线右侧的矩形线圈。试确定：(3) 矩形线圈以直导线为轴旋转时，ABCD 上的感应电动势的方向。

第0步 · 三类检查

(i) 存在性与模型前提：导线为转轴，线圈平面始终包含导线；线圈绕轴转动时，它与导线的相对位置关系按对称性保持。

(ii) 多值与分支：结论是“无电动势”，没有方向分支；但要分清“有速度”与“有切割”是两件事。

(iii) 取值范围：旋转角可取 0 到 2π，线圈不越过导线（r 保持正）。

思路

路线甲：对称性。转动前后线圈相对磁场的位置关系不变，磁通量不变。

路线乙：洛伦兹力。看每一点的速度与 B 是否平行。

选甲给出结论，乙解释为什么每一段都不产生电动势。

分步推导
  1. 看几何关系：线圈绕导线转动时，线圈平面始终包含导线。
  2. 看磁场：长直导线的 B 在每一点都垂直于“过该点与导线的平面”，也就是垂直于线圈平面；B 的大小只由该点到导线的距离决定。（依据：(1-2) 的方向与大小）
  3. 判磁通量：转动中线圈上各点到导线的距离不变，线圈形状不变，所以 Φ 不变。（依据：(1-1)）
  4. 得结论：Φ 不变，由 (2-1)，ε=-dΦ/dt=0，回路中无感应电流。
答案\[ \boxed{\varepsilon=0,\ \text{无感应电流}} \]
验证

独立路径（洛伦兹力）：线圈上任一点的速度沿“绕导线的圆”的切向，B 也沿同一圆的切向，两者平行，所以 v×B=0。每一段的动生电动势都为零，与磁通量结论一致。

合理性检查：绕导线转动是磁场关于导线的对称操作，转动前后物理情形完全相同，磁通量没有理由变化。

常见坑
① “线圈在磁场中转动就一定有电动势”。发电机线圈绕自身轴转，边在切割磁感线；本题绕导线转，速度与 B 平行，v×B=0。
② 把“绕导线转”与“绕线圈自己的一条边转”混淆：后者的轴不在导线上，各点到导线的距离会变，一般不出现零电动势。
③ 只看到“线圈每一刻都在移动”，没有检查速度与 B 的夹角。有没有电动势由 v×B 决定，不由“有没有速度”决定。

题 12-3　磁铁在两线圈之间向右运动

题目重述

如图所示，有两个平行静止放置的线圈 A 和 B。若有一条形磁铁向右运动（磁铁的 S 极朝左、N 极朝右，两线圈与磁铁同轴，A 在左、B 在右），则两线圈中感应电动势和感应电流的方向各如何？

第0步 · 三类检查

(i) 存在性与模型前提：磁铁沿两线圈的公共轴线平移，两线圈静止；把两个线圈各自独立处理（先不计它们之间的互感）。

(ii) 多值与分支：每个线圈都要单独给出方向，而且必须写明“从哪一侧看”的顺、逆时针，否则同一个电流可以有两种叫法。

(iii) 取值范围：磁铁在两线圈之间向右运动，同时靠近 B、远离 A；两个过程同时发生，但要分别判断。

思路

路线甲：楞次定律，逐线圈判断磁通量增减。

路线乙：“来拒去留”的等效磁极判据。

选甲：需要先判断磁场方向，能顺带把“A 处磁场朝哪边”这个易错点讲清楚；乙放在验证里。

分步推导
  1. 判磁铁的磁场：磁感线在外部从 N 极出发、回到 S 极。在轴线上，磁铁左右两侧的 B 都指向右：左侧的场线进入 S 极，右侧的场线离开 N 极。（依据：磁感线闭合 + 外部从 N 到 S）
  2. 看线圈 B：磁铁向右靠近，B 处磁场增强，穿过 B 的向右磁通量增加。
  3. 定感应磁场：按“增反”，B 中感应磁场向左。（依据：楞次定律）
  4. 定磁极：感应磁场从 B 的左端面穿出，所以左端面相当于 N 极。
  5. 定电流方向：从磁铁一侧（B 的左侧）向右看，感应磁场指向观察者，电流为逆时针。（依据：右手螺旋定则）
  6. 看线圈 A：磁铁向右远离，A 处向右的磁通量减少。
  7. 定感应磁场：按“减同”，A 中感应磁场向右。（依据：楞次定律）
  8. 定磁极：感应磁场从 A 的右端面穿出，所以右端面相当于 N 极。
  9. 定电流方向：从磁铁一侧（A 的右侧）向左看，感应磁场指向观察者，电流为逆时针。（依据：右手螺旋定则）
答案\[ \boxed{\text{两线圈面向磁铁的端面都是 N 极：}A\text{ 吸引、}B\text{ 排斥};\ \text{从磁铁处看，两线圈电流都逆时针}} \]
验证

换列式复核（等效磁极）：B 需阻碍磁铁靠近，面向磁铁的一端与磁铁的 N 极同名，即 N 极；A 需阻碍磁铁远离，面向磁铁的一端与磁铁该端的 S 极异名，也是 N 极。这与第 4、8 步的磁极结论一致。

合理性检查：两个线圈都在“拖住”磁铁，磁铁的动能转化为线圈的焦耳热，能量守恒。

常见坑
① 以为“A 在 S 极旁边，A 处磁场指向左边”。轴线外侧的场线要回到 S 极，方向指向磁铁（向右）；判反会让 A 的电流整体反向。
② 只说顺时针或逆时针，不写观察方向。从磁铁一侧看与从外侧看，结论相反。
③ 用“靠近 N 极就感应出 N 极”的死记法套到 A。A 面向的是 S 极，正确判据是“阻碍相对运动”，不是“同极相斥”。
小结卡方向类题的三步闭环：先定 B 的方向，再判 Φ 的增减，最后用右手螺旋把感应磁场换成电流。核对用“增反减同”与“来拒去留”。长直导线两侧 B 方向相反，这是本模块所有错误的源头。
M2定量

M2 · 法拉第定律的定量计算

知识点

① 法拉第电磁感应定律（单匝回路；N 匝时右边乘 N）：

\[ \varepsilon=-\frac{d\Phi}{dt} \tag{2-1} \]

负号是楞次定律的数学表述，只负责方向；求大小时取绝对值。平均电动势为 ε=-ΔΦ/Δt，瞬时电动势取极限。

② B 变化而 S、θ 不变时，把 (1-1) 代入 (2-1) 求导：

\[ \varepsilon=-S\cos\theta\,\frac{dB}{dt} \tag{2-2} \]

③ 感生电场的环路定理：变化磁场在空间激发涡旋电场，绕任意闭合回路的线积分等于该回路磁通量的变化率：

\[ \oint_L \mathbf{E}\cdot d\mathbf{l}=-\frac{d\Phi}{dt} \tag{2-3} \]

④ 磁通量只算有磁场的面积。磁场被限制在某个区域内时，穿过回路的磁通量等于“回路所围面积中落在磁场内的那部分”乘以 B。回路电阻为 R 时：

\[ I=\frac{S_{\text{内}}}{R}\left|\frac{dB}{dt}\right| \tag{2-4} \]
解题方法
  1. 圈出回路的“有效面积”：回路所围面积中真正有磁场的部分，记作 S内。
  2. 写出 Φ 的表达式并定符号（先选正法线）。
  3. 求导得 ε（或求 ΔΦ/Δt 得平均电动势）。
  4. 求电流：I=|ε|/R回路；题目未给电阻时，用符号 R 表示，或说明题目实际只可求电动势。
  5. 方向：另用楞次定律判断，符号只作核对。
适用条件：回路刚性、形状简单，能写出 Φ(t)。 本模块易错点：θ 是与法线的夹角；把没有磁场的区域也算进磁通量；B 很大但不变时误判有电动势。

题 12-4　θ 取何值时 ε 最大、最小

题目重述

有一面积为 S 的导电回路，其正法线 e_n 的方向与均匀磁场 B 的方向之间的夹角为 θ，且 B 的大小随时间的变化率为 dB/dt。试问 θ 角为何值时，回路中 ε 的值最大；θ 角为何值时，ε 的值又最小？请解释之。

第0步 · 三类检查

(i) 存在性与模型前提：磁场均匀；回路为平面、面积 S 固定；θ 固定，只有 B 的大小随时间变化。

(ii) 多值与分支：θ 的定义域为 0 到 π。|cosθ| 在 θ=0 与 θ=π 同时取 1，两处的 ε 符号相反、绝对值相同。题目问“值最大、最小”，按绝对值回答，并注明代数值的区别。

(iii) 取值范围：cosθ 在 -1 到 1 之间，所以 |ε| 在 0 到 S|dB/dt| 之间。

思路

路线甲：由 (2-1) 完整求导。

路线乙：只看“有效面积”S cosθ 的变化。

两条路线是同一件事。选甲写出完整式子，乙用于核对。

分步推导
  1. 写磁通量：Φ=BScosθ。（依据：(1-1)）
  2. 求导：S 与 θ 不随时间变，只有 B 变，所以 dΦ/dt=Scosθ·dB/dt。（依据：乘积求导，S cosθ 为常数因子）
  3. 写电动势：ε=-dΦ/dt=-Scosθ·dB/dt。（依据：(2-1)）
  4. 取大小：|ε|=S|cosθ|·|dB/dt|。（依据：(2-2)）
  5. 找最大值：|cosθ|=1 即 θ=0 或 θ=π 时，|ε|=S|dB/dt|，为最大。
  6. 找最小值：|cosθ|=0 即 θ=π/2 时，|ε|=0，为最小。
  7. 解释：只有垂直于回路平面的 B 分量 Bcosθ 才提供磁通量；θ=π/2 时 B 与回路平面平行，磁感线不穿过回路，Φ 恒为零，B 变化也不产生磁通量变化。（依据：(1-1) 中的 cosθ 因子）
答案\[ \boxed{\theta=0\ \text{或}\ \pi:\ |\varepsilon|_{\max}=S\left|\frac{dB}{dt}\right|;\qquad \theta=\frac{\pi}{2}:\ \varepsilon=0} \]
验证

换记号复核（投影面积）：把 S cosθ 看作回路在垂直于 B 的平面上的投影面积 S⊥，则 ε=-S⊥·dB/dt，与第 3 步一致；θ=π/2 时 S⊥=0，ε=0。

合理性检查：电动势取决于磁通量的变化率，与 B 本身的大小无关。若 dB/dt=0，任何 θ 都没有电动势，这与公式中的乘积结构一致。

常见坑
① 把 θ 当成“B 与回路平面的夹角”，写成 sinθ：最大值点被搬到 θ=π/2，与正确答案正好互换。
② 认为 θ=π 时“ε 最小”。代数值确实最小（负得最多），但题目问“值”的大小；回答时应同时说明 |ε| 与符号。
③ 丢掉“B 均匀”的前提。非均匀磁场不能直接写 BScosθ，要回到积分。

题 12-5　用两个电流脉冲测炮弹速度

题目重述

有人认为可以采用下述方法来测量炮弹的速度。在炮弹的尖端插一根细小的永久磁针，那么，炮弹在飞行中连续通过相距为 r 的两个线圈后，由于电磁感应，线圈中会产生时间间隔为 Δt 的两个电流脉冲。您能据此测出炮弹速度的大小吗？若 r=0.1 m，Δt=2×10⁻⁴ s，则炮弹速度的大小为多少？

第0步 · 三类检查

(i) 存在性与模型前提：磁针随炮弹一起平动；两个线圈同轴、静止、相距 r；磁针尺寸远小于 r；飞行中速度近似不变。

(ii) 多值与分支：单个线圈的磁通量先增后减，所以电动势先正后负，形成一个双极性脉冲。取时间间隔时必须取同类特征点（例如两个过零点之间，或两个同号峰之间），否则结果偏大或偏小。

(iii) 取值范围：r 固定、Δt 很小，算得的速度在数百米每秒的量级，与常规弹速相符。

思路

路线甲：从“脉冲的过零点出现在磁针经过线圈平面的时刻”直接得 v=r/Δt。

路线乙：由 ε=-dΦ/dt 分析磁通量的极值，说明过零时刻确实对应磁针经过线圈平面。

选乙：先把依据讲清，甲作为结论。

分步推导
  1. 看单个线圈的磁通量：磁针靠近时增大，经过线圈平面时取最大值，离开时减小。
  2. 看电动势：ε=-dΦ/dt。磁针经过线圈平面时 Φ 最大、ε=0；在此之前与之后，ε 的符号相反。所以一个线圈中出现的是一个正负交替的脉冲，脉冲的过零时刻对应磁针经过线圈平面的时刻。（依据：(2-1)）
  3. 取对应特征：两个线圈与磁针的条件相同，两个脉冲的形状相同。取同一特征（两个过零点之间，或两个同号峰之间）量出的间隔，就是磁针从第一个线圈平面走到第二个线圈平面所用的时间。
  4. 看两个脉冲的间隔：Δt 就是磁针从第一个线圈平面走到第二个线圈平面所用的时间。
  5. 写位移与速度：这段位移约为两线圈间距 r，故 v=r/Δt。（依据：匀速近似）
  6. 代入数值：v=0.1/(2×10⁻⁴)=5.0×10² m/s。
答案\[ \boxed{v=\frac{r}{\Delta t}=5.0\times10^{2}\ \text{m/s}} \]
验证

量纲与数量级检查：r/Δt 的单位是 m/s。数值 500 m/s 落在手枪弹（约 300～400 m/s）与步枪弹（约 700～900 m/s）之间，量级合理。

灵敏度检查：v 与 Δt 成反比，Δt 测得偏大 1%，v 就偏小 1%，相对误差直接传递。合理性检查：速度越大，同样距离用时越短，两个脉冲靠得越近，与 v=r/Δt 一致。

常见坑
① 把“脉冲的宽度”当成 Δt。那是磁针穿过一个线圈所用的时间，与 r 无关，算出来的不是弹速。
② 取一个脉冲的正峰与另一个脉冲的负峰。Δt 不是同类特征点的间隔，速度会系统性偏大或偏小。
③ 忘记“磁针与线圈同轴”这一前提。磁针倾斜时脉冲形状改变，过零时刻偏离线圈平面。

题 12-8　柱形磁场中三个回路的电流

题目重述

如图所示，均匀磁场被限制在半径为 R 的圆柱体内，且磁感强度大小随时间的变化率为 dB/dt=常量。试问：回路 L1、L2 和 L3 上的感应电流各为多少？

说明：原题图在截图里被下方工具栏遮住。按标准图形处理：L1 与圆柱同轴、整个在磁场区内（半径 r1 小于 R）；L2 与圆柱同轴、整个在磁场区外（半径 r2 大于 R）；L3 与磁场区边界相交，一部分面积在区内。若手上的图与此不同，只需把 S内 换成相应的“区内面积”，方法完全相同。

R L1 L3 L2

第0步 · 三类检查

(i) 存在性与模型前提：柱形区域内有均匀 B（垂直纸面向里），区域外 B=0；三个回路都是平面回路，位于垂直于柱轴的平面内。

(ii) 多值与分支：磁通量只算柱体内那部分面积；电流方向分“B 增大”与“B 减小”两种情形，两种都要给出。

(iii) 取值范围：S1内=πr1²；S2内=πR²（与 r2 无关）；S3内 由 L3 的形状决定，介于 0 与 πR² 之间。

思路

路线甲：磁通量法，逐个回路算“区内面积”，再用 (2-1) 求电动势。

路线乙：感应电场的环路定理 (2-3)。

选甲求电动势与电流；乙放在验证里，顺便解释 L2 为什么与半径无关。

  2. 算 L1：整个回路在区内，S1内=πr1²，Φ1=Bπr1²。
  3. 算 L2：回路把整个柱体包住，柱体外没有磁场，S2内=πR²，Φ2=BπR²。它与 r2 无关。
  4. 算 L3：只有落在柱体内的那部分面积贡献磁通量，Φ3=B·S3内。
  5. 求电动势：εk=-dΦk/dt=-S内·dB/dt。（依据：(2-1)）
  6. 求电流：Ik=|εk|/Rk=S内|dB/dt|/Rk，R1、R2、R3 为各回路的电阻。（依据：(2-4)）
  7. 定方向：若 B 向里且增大（dB/dt 为正），感应磁场向外，三个回路中的电流都沿逆时针（从纸面这一侧看）；B 减小时都沿顺时针。（依据：楞次定律）
答案\[ \boxed{I_1=\frac{\pi r_1^2}{R_1}\left|\frac{dB}{dt}\right|,\quad I_2=\frac{\pi R^2}{R_2}\left|\frac{dB}{dt}\right|,\quad I_3=\frac{S_{3\text{内}}}{R_3}\left|\frac{dB}{dt}\right|} \]
验证

独立路径（感应电场环路定理 (2-3)）：柱内电场 E(r)=(r/2)|dB/dt|，沿同心圆。对 L1：∮E·dl=E(r1)·2πr1=πr1²|dB/dt|，与第 5 步一致。柱外电场 E(r)=(R²/2r)|dB/dt|，对 L2：∮E·dl=E(r2)·2πr2=πR²|dB/dt|，也与 r2 无关——周长按 r 增长、场强按 1/r 衰减，两者正好抵消。

合理性检查：L2 处于“没有磁场”的区域却仍有电动势，原因是感生电场存在于柱外；若 L2 的电动势随 r2 增大，远处的回路就能“白得”电动势，与能量守恒矛盾。

常见坑
① 认为“L2 处没有磁场，所以没有电动势”。磁通量变化通过感生电场起作用，柱外同样有涡旋电场。
② 把 L2 的磁通量算成 πr2²B，把无磁场区域也算进去。正确值是 πR²B。
③ 题目问电流，却直接把电动势当答案。电流必须除以各回路的电阻；未给电阻时只能用 Rk 表示，或说明实际只能求电动势。
小结卡定量题只有两件事：算对“区内面积”，再对时间求导。磁通量只认有磁场的部分；|ε| 只与变化率有关，与 B 本身大小无关；电流还要除以回路电阻。
M3动生

M3 · 动生电动势与磁场的边界

知识点

① 动生电动势：导体在磁场中运动，正电荷受洛伦兹力 qv×B，沿导线的分量把电荷“泵”起来。直段、v 与 B 垂直且三者互相垂直时：

\[ \varepsilon=Blv \tag{3-1} \]

② 只有切割的段贡献：ε=∫(v×B)·dl，v×B 垂直于导线的部分不产生电动势。与 v、B 都平行的段贡献为零。

③ 边界效应：回路全部浸没在均匀磁场中平动时，Φ 不变，ε=0；只有部分进入或部分穿出时才有净电动势，因为这时 Φ 在变。

④ 自由下落：v=gt（按题意忽略安培力对速度的影响），所以 |ε| 随时间增大。

解题方法
  1. 标 B、v，找出每个阶段的“有效切割边”（在磁场内、且 v×B 沿导线的边）。
  2. 分阶段：进入前、进入中、全在磁场内、穿出中、穿出后。
  3. 每段写 Φ(t) 或直接用 (3-1)，两种算法互检。
  4. 方向用楞次定律或 v×B 判断，注意进入与穿出方向相反。
  5. 速度变化时，把 v(t) 代入，说明大小的变化趋势。
适用条件：刚性线框、匀强有界磁场、平动（不转动）。 本模块易错点：以为“在磁场中运动就有电动势”；漏掉“全在磁场内 ε=0”这一段。

(iii) 取值范围：按位置分五段：未进入（ε=0）、进入中（部分在磁场内）、全在磁场内（ε=0）、穿出中（部分在磁场外）、穿出后回到 0。

  2. 写磁通量：设水平边长为 l，下边进入磁场的深度为 x=v t，则 \[ \Phi=Blx=Blvt \]
  3. 求电动势：ε=-dΦ/dt=-Blv，大小 |ε|=Blv。（依据：(2-1)）
  4. 定进入阶段的方向：向里的磁通增加，感应磁场向外，电流逆时针。等价地：下边中正电荷受 qv×B（v 向下、B 向里），受力向右，下边电流向右，回路电流逆时针。
  5. 看完全进入阶段：上、下边都在磁场内，Φ=Blh（h 为线框高度）不变，ε=0。上、下两边都切割磁感线，但两边电动势大小相等、方向相反，沿回路互相抵消。
  6. 看穿出阶段：下边已出磁场（B=0），上边仍在磁场内切割磁感线。Φ 随下落减小，感应磁场向里，电流顺时针。
  7. 写大小：两个阶段都有 |ε|=Blv；自由下落 v=gt，所以 |ε| 随时间增大。
  8. 完整体：全部穿出后 B=0，ε 回到 0。
答案\[ \boxed{\text{进入：}|\varepsilon|=Blv\ \text{逆时针};\quad \text{全在：}\varepsilon=0;\quad \text{穿出：}|\varepsilon|=Blv\ \text{顺时针};\quad \text{穿出后：}0} \]
验证

独立路径（洛伦兹力与磁通量互检）：进入时用下边的 v×B 得 Blv 与逆时针，与磁通量法一致；穿出时用上边的 v×B 得顺时针，与“磁通减少”一致。

合理性检查：完全进入后磁通量不变，ε=0；进入与穿出时感应电流都产生焦耳热，能量来自线框减少的重力势能（安培力向上，阻碍下落），符合能量守恒。

常见坑
① 认为“线框在磁场中运动就有电动势”。完全进入后 ε=0，这是本题最容易丢分的一句。
② 认为电动势在“完全进入”时最大。那一时刻恰好为零；最大出现在部分进入或部分穿出的过程里。
③ 把进入、穿出两个阶段的方向判成相同。两个阶段的电流都使安培力向上，但磁通变化方向相反，电流方向也相反。
④ 忘了 v 在增大，答成“恒为 Blv”。
小结卡动生题先分段，再找切割边。进入与穿出的电动势大小相同、方向相反；完全浸没时磁通量不变，电动势为零。速度变化时，电动势随之变化。
M4本质

M4 · 感应电场、涡流与电动势的本质

知识点

① 感生电场（涡旋电场）：变化磁场在空间激发电场，它的场线闭合、不是保守场，绕回路的线积分等于磁通变化率，见 (2-3)。它与是否存在导体、是什么材料都无关。

② 涡流：导体内部的感生电流。有导体时有涡流，会产生焦耳热，并产生阻碍磁通变化的磁场。

③ 电动势的定义：把单位正电荷沿回路移动一周时，非静电力所做的功：

\[ \varepsilon=\oint \frac{\mathbf{F}_{\text{非}}}{q}\cdot d\mathbf{l} \tag{4-1} \]

电池的非静电力是化学作用；感应电动势的非静电力是感生电场力。电动势不是静电场做的功。

解题方法
  1. 先答“是否存在”：电场看 dΦ/dt 是否为零；电流还要看有没有自由电荷。
  2. 再答“为什么”：给出判据（(2-3)、欧姆定律的微观形式）。
  3. 最后答“边界情形”：无导体、磁场不变、完全插入之后。
  4. 比较两类电动势时，从定义式 (4-1) 出发：共同点来自同一个定义，不同点来自 F非 的来源与分布。
适用条件：概念题，重判据不重计算。 本模块易错点：把“场”与“电流”混为一谈；把静电场当成电动势的来源。

题 12-2　铜环与塑料环中的电场和电流

题目重述

当我们把条形磁铁沿铜质圆环的轴线插入铜环中时，铜环中有感应电流和感应电场吗？若用塑料圆环替代铜质圆环，则环中仍有感应电流和感应电场吗？

第0步 · 三类检查

(i) 存在性与模型前提：磁铁沿环轴插入，穿过环的磁通量在变化；环是铜（导体）或塑料（绝缘体）。

(ii) 多值与分支：分“插入过程中”与“完全插入后”两个时段；分铜、塑料两种材料；每种都要分别回答“电场”与“电流”。

(iii) 取值范围：插入过程中 dΦ/dt 不为零；完全插入后磁铁静止，dΦ/dt=0。

思路

路线甲：从感生电场的产生条件出发（只与 dΦ/dt 有关），再判电流（需要自由电荷）。

路线乙：从欧姆定律 I=ε/R 出发，看电阻的差别。

选甲：它能把“场”与“电流”两件事分开，乙只解释电流的差别。

分步推导
  1. 看磁通量：插入过程中，穿过圆环的磁通量随时间变化，dΦ/dt 不为零。
  2. 定电场：由 (2-3)，变化磁场在周围空间激发感生电场；这一步与环的材料无关，所以铜环、塑料环中都有感生电场。依据：感生电场旁注 · 感生电场是什么它是变化磁场在空间激发出的涡旋电场：场线闭合，沿闭合回路积分等于磁通量变化率。它由磁场的变化决定，不需要导体来“承载”，也不需要回路闭合。本题用法：先判“有没有场”，再判“有没有电流”；第二步才用材料（自由电荷多少）。。
  3. 判铜环：铜是导体，环内有大量自由电子；感生电场对电子施力，电子定向移动，形成感应电流（涡流）。（依据：欧姆定律的微观形式）
  4. 判塑料环：塑料是绝缘体，几乎没有自由电荷；感生电场只能使束缚电荷发生微小位移，不能形成宏观电流，所以塑料环中无感应电流。
  5. 补边界情形：完全插入后磁铁静止，磁通量不再变化，dΦ/dt=0，感生电场与电流都消失。
答案\[ \boxed{\text{铜环：有感应电场，也有感应电流};\qquad \text{塑料环：有感应电场，无感应电流}} \]
验证

换列式复核（I=ε/R）：两种材料的 ε 相同，铜的电阻很小，电流明显；塑料的电阻极大，电流趋于零。结论与上面一致。

合理性检查：电动势是场的属性，电流还要载流子。若把塑料环视为理想绝缘体，R 趋于无穷，I=0 而 ε 不变。

常见坑
① 认为“没有导体就没有感生电场”。把电场当成了电流的伴生现象；电场由 dΦ/dt 决定，与材料无关。
② 认为“塑料环里没有电流，所以没有电动势”。电动势 ε=∮E·dl 与材料无关，只是 I=ε/R 中的 R 极大。
③ 忘了“完全插入后”这一阶段，把“有电流”当成永久状态。

题 12-7　感应电动势与电池电动势的异同

题目重述

在一闭合回路中，由变化磁场激起的感应电动势与由回路电池产生的电动势有哪些共同之处？又有哪些不同呢？

第0步 · 三类检查

(i) 存在性与模型前提：两者都满足电动势的一般定义 (4-1)；比较的对象是“稳恒电池”与“随时间变化的磁场引起的感应电动势”。

(ii) 多值与分支：比较题必须分“共同点”与“不同点”两条线作答，不能混在一起。

(iii) 取值范围：电池近似稳恒；感应电动势的大小与方向随 dB/dt 改变。

思路

路线甲：从统一的定义式 (4-1) 出发：共同点来自同一个定义，不同点来自 F非 的来源与分布。

路线乙：按“起源、场、分布、能量、方向”逐项列表。

选甲作主干，乙负责展开细目。

分步推导
  1. 写定义：两者都等于把单位正电荷沿闭合回路移动一周时非静电力做的功，ε=∮(F非/q)·dl。（依据：(4-1)）
  2. 比作用：两者都能在闭合回路中维持电流，并在回路两端维持电势差——都把正电荷从低电位“泵”到高电位。（依据：电动势的功能定义）
  3. 比能量：两者都把非电能转换为电能。电池把化学能转换为电能；感应电动势把磁场能量（或维持磁场的机械功、电源能量）转换为电能。
  4. 比电路规律：两者都服从 I=ε/(R+r) 形式的欧姆定律，R 为外电阻，r 为内阻。
  5. 比来源：电池的非静电力是化学作用（电极与电解质的电化学过程）；感应电动势的非静电力是变化磁场激发的感生电场力。
  6. 比场的性质：感生电场是涡旋场、非保守场，∮E感·dl=-dΦ/dt 不为零；电池内部的非静电力不是静电场，电池两极间的静电场是保守场，∮E静·dl=0，静电场本身不能提供电动势。（依据：(2-3)）
  7. 比空间分布：感生电场充满空间，感应电动势分布在回路各处；电池的非静电力只存在于电池内部（电极与电解质界面）。
  8. 比存在条件与方向：只要有变化磁场，感生电场就存在，不需要导体、不需要回路；电池电动势必须有电池装置。感应电动势的方向随 dΦ/dt 的符号改变，电池的极性固定。
答案\[ \boxed{\text{共同：都等于单位正电荷绕回路一周非静电力做的功，都能维持电流与电势差、转换能量};\ \text{不同：非静电力来源、场的性质、空间分布、存在条件、方向}} \]
验证

换列式复核（统一公式）：把 F非=F化学 与 F非=qE感 分别代入 (4-1)，共同点全部来自这个定义式，不同点全部来自两种 F非 的来源与分布。

合理性检查：若没有“非静电力”这个共同本质，就无法解释两件事——副线圈里没有电池却有电动势；电池内部静电场的方向与电动势的方向相反。

常见坑
① 把感应电动势说成“静电场做的功”。静电场是保守场，∮E静·dl=0，不可能提供电动势。
② 只答“都有电动势、都能产生电流”，没有指出“非静电力”这个共同本质。
③ 认为“感应电动势只存在于导体回路中”。感生电场不需要导体，回路只是用来“测量”它。
小结卡场与电流分开看：ε 由 dΦ/dt 决定，I=ε/R 还取决于材料。两类电动势的共同本质是“非静电力做功”；差别全部来自非静电力的来源与分布。
